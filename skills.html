Skills — the S0 wrappers

Each skill is a pure function in framework/skills.py. S2 passes parameters; the function returns a typed Skill whose IR steps framework.s0 compiles into a 50 Hz wrist+object reference trajectory for the frozen S0 (first streamed chunk ~18 ms). Compose several with program(object_key, [skill, …]); a Graph validates the chain against the Capability Atlas before execution. This page is generated by introspecting the code, so it matches exactly.
