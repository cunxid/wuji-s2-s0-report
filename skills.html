Skills — interactive reference generators

Each skill is a fixed wrapper: parameters in → a 50 Hz wrist(+object) reference out; the frozen S0 tracks it and physics decides. These panels run the same analytic shapes the wrappers compose (cosine-eased segments, slerp tilts) in your browser — type numbers, see the reference it would generate. Per-parameter measurements live on the capability page.

Correction, 2026-11-23. Three panels on this page (spin, pour, strike) used to quote results next to the generated reference: per-object in-hand rotation “walls”, a pour that “reaches 146°”, and a strike elevation band labelled “mallet-down”. An audit of every reported pass found that the rotation and pour figures came from scores that did not measure what they claimed, and that the strike was a push along the handle that left the nail where it started. The three panels now say what the audit found instead. The reference generators are unchanged, and so are the ✅ / ⚠ envelope lines, which come from tracking measurements the audit did not cover. Full record: audit of reported passes.

Frames: table top at z≈0.92 m, grasp anchor at (-0.32, -0.45). Eased position segments use p(t)=p₀+(p₁-p₀)·(0.5-0.5cos(πt)) at 50 Hz — identical to the cosim composer’s _seg. Rendering is an isometric projection (right-handed, z up); the orange dot marks the start, the red dot the end; the side strip plots the time profile. These are references, not rollouts: whether S0 can track a given parameter set is exactly what the capability atlas measures.
