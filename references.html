Frameworks this work positions against

  • ASPIRE — Lu, Wu, Kou, … Zhu, Fan, Wang (NVIDIA GEAR), ASPIRE: Agentic Skills Discovery for Robotics, arXiv:2607.00272, 2026. An LLM coding agent writes/repairs code-as-policy programs over a frozen primitive API and accumulates a reusable skill library. We borrow its accumulated-memory idea — probing campaigns fill a persistent Capability Atlas. research.nvidia.com/labs/gear/aspire · github.com/NVlabs/ASPIRE.
  • GaP (Graph-as-Policy) — Chen et al. (UC Berkeley; Goldberg, Sastry, …), GaP: A Graph-as-Policy Multi-Agent Self-Learning Harness for Variational Automation Tasks, arXiv:2607.05369, CoRL 2026 (Spotlight). LLM-composed computation graphs as policies. We borrow its typed-graph execution — framework/graph.py validates a Skill-node graph against the Atlas before running. graph-robots.github.io/gap.
  • AGP (Agent as Policy) — Jia, Lin, Zhang, Zhang, Liu, Jiang, Agent as Policy for Robotic Manipulation, arXiv:2609.12541, 2026. LLM robot agent with online visual feedback and runtime replanning — related to our stage-keyed retry ladder.
  • SuperMimic — Liao, Shao, Long, Zakka, Horowitz, Abbeel, Sreenath (UC Berkeley), SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model, arXiv:2610.28480, CoRL 2026 (Oral). Differentiable-world-model RL for humanoid whole-body control (transfers to Unitree G1). The sister project on this machine (Dex-Supermimic) adapts this approach to a dexterous hand. supermimic.github.io.

Foundational methods

  • Code as Policies — Liang, Huang, Xia, Xu, Hausman, Ichter, Florence, Zeng (Google), Language Model Programs for Embodied Control, ICRA 2023, arXiv:2209.07753. The lineage for "LLM emits a program the robot executes," which our Skill/program layer follows in a frozen-policy setting. code-as-policies.github.io.
  • Voyager — Wang, Xie, Jiang, Mandlekar, Xiao, Zhu, Fan, Anandkumar, An Open-Ended Embodied Agent with Large Language Models, arXiv:2305.16291, 2023. The lineage for a growing, reusable skill library (our Atlas is the boundary-model analog). voyager.minedojo.org · github.com/MineDojo/Voyager.
  • MuJoCo — Todorov, Erez, Tassa, A physics engine for model-based control, IROS 2012.

Simulation & tooling

  • MuJoCo Warp — GPU-accelerated differentiable MuJoCo. github.com/google-deepmind/mujoco_warp. The GPU probing route batches on it.
  • mjlab — Manager-based RL environment framework on MuJoCo Warp. github.com/mujocolab/mjlab. S0's environment (ManagerBasedRlEnv) is built on it.
