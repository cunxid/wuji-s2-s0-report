Can closed-loop task programs make a frozen dexterous tracking policy task-general?

S2 experiment writeup · frozen AUTO3 Mixed model_8000.pt (Object-only) · hand_table_v1 · deterministic placements · all numbers computed from run artifacts

Abstract. We study whether a frozen whole-hand tracking policy (S0) can execute five everyday tool tasks across varied scene placements when driven by task programs, and how far closed-loop program structure (measure-then-act steps) extends its reach. On a pre-registered grid of 48 task-scenes across five tasks, the original single-scene-validated programs succeed on 29/48 (60%). Replacing every hold-calibrated open-loop constant with its closed-loop equivalent — align_actual re-anchoring for aims, keep_point re-centering for sustained tool-tip contact, sag-corrected depth targets, and removal of one fragile open-loop step — raises this to 41/48 (85%) with no per-scene tuning. Per-scene program selection between the two candidates (the decision an Atlas-informed planner makes) reaches 42/48 (88%). A leave-one-out ablation attributes the screwdriver task's 0/5→5/5 recovery chiefly to depth correction and closed-loop re-centering. Residual failures are two acquire-marginality cells, consistent with the measured grasp boundary maps.

1 · Setup

Executor: the deployment-faithful gated episode runtime (reference held until lift confirmation; one episode per process; deterministic simulation — variance across the grid comes from placements, not seeds). Tasks and scoring: each task's own action-level criteria (e.g. strikes counted by the face arriving downward at the target; screw-driving counted only while the tip is inside an 8 mm/±10 mm zone), which supersede generic drop monitors. Scene grids: the original 28-scene grid plus a held-out extension defined before any run (object yaw within each object's measured pick band × systematically rotated/raised targets). Programs are fixed per condition across ALL scenes.

5 · Limitations

One deterministic rollout per scene (no stochastic replication — the simulator is deterministic and edge cells were separately shown to be sharp under 2 mm jitter); a single object instance per task; simulation only (the screwdriver task is known to succeed on the real robot with the ORIGINAL program, so sim-fixes may over- or under-state real-robot deltas); the held-out grid, while pre-registered, samples the same scene family as the original grid.
